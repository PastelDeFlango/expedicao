EXPEDICAO CONTROL - SERVIDOR
============================

COMO INICIAR
------------
1. npm install
2. copy .env.example .env
3. npm start

Acesse: http://localhost:3000

IMPORTANTE
----------
Extraia em pasta SEM parenteses no caminho. Certo: C:\expedicao
Use Node.js 20 LTS.

TESTE DA SINTAXE
----------------
node --check src/server.js
node --check src/db.js

ACESSOS INICIAIS
----------------

2. Fim da montagem de carga

4. Veiculo docado
5. Inicio do carregamento
6. Fim do carregamento

8. Liberacao do veiculo
